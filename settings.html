Production Deployment Notes
Checklist for deploying RedFlagged in a production environment
Security
☐ Move secrets to Azure Key Vault or environment variables
☐ Enable HTTPS (reverse proxy: Nginx / Azure App Service)
☐ Restrict network access — internal IP range or VPN only
☐ Enable Azure AD authentication (MSAL) for dashboard login
☐ Remove debug=True from server.py
Infrastructure
☐ Run with gunicorn: gunicorn server:app -w 2
☐ Use a process manager (systemd / PM2 / Docker)
☐ Replace in-memory cache with Redis for multi-worker support
☐ Set up log rotation and monitoring
☐ Configure auto-restart on failure
⚠️
config.json stores credentials in plaintext. For production, use environment variables (TENANT_ID, CLIENT_SECRET, etc.) and remove config.json from the deployment or add it to .gitignore.
